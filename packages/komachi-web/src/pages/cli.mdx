The Komachi CLI runs through npx, so there's nothing to install.

```bash
npx @swiftlylabs/komachi help
```

## Installing a block

Blocks are copy-paste compositions you own and can edit.

```bash
# Initialize komachi.json configuration
npx @swiftlylabs/komachi init

# List all available blocks
npx @swiftlylabs/komachi blocks

# Install a block to your project
npx @swiftlylabs/komachi add PageHeader
```
