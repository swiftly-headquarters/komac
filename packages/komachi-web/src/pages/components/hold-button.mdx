## Usage

Use `onHoldComplete` for the protected action. `HoldButton` suppresses ordinary
click activation, so releasing early never runs the action.

```tsx
import { HoldButton } from "komachi";

export default function Example() {
  return (
    <HoldButton
      effect="fill"
      holdDuration={1200}
      onHoldComplete={() => deploy()}
    >
      Hold to deploy
    </HoldButton>
  );
}
```

Pointer, touch, Space, and Enter holds use the same duration. Releasing, moving
the pointer away, cancelling the pointer, or moving focus before completion
resets progress and calls `onHoldCancel` when provided.

## Examples

### Effects

Choose an effect that matches the action and available space. Every effect uses
the same hold timer and reaches completion at the configured duration.

<ComponentExample demo="HoldButtonEffectsDemo" vrSection="effects-all" vrTitle="All Effects">
  <HoldButtonEffectsDemo client:load />
</ComponentExample>

### Durations

Use a short duration for accidental-click protection and a longer duration for
consequential actions. The default duration is `1200` milliseconds.

<ComponentExample demo="HoldButtonDurationsDemo" vrSection="durations" vrTitle="Durations">
  <HoldButtonDurationsDemo client:load />
</ComponentExample>

### Button Variants

`HoldButton` supports Button variants, sizes, shapes, icons, loading state, and
disabled state. Destructive variants automatically use the danger color for
progress effects.

<ComponentExample demo="HoldButtonVariantsDemo" vrSection="button-variants" vrTitle="Button Variants">
  <HoldButtonVariantsDemo client:load />
</ComponentExample>

### Cancellation

Use `onHoldCancel` when the interface should acknowledge an interrupted hold.
Completion followed by release does not count as cancellation.
